# send-2-kindle

Send documents to your Kindle from the terminal — or let Claude prepare and send them for you.

| Part | What it is | Install |
|---|---|---|
| [`cli/`](cli/README.md) | `s2k`, a command-line tool that emails files to your Kindle (Send to Kindle) | `pipx install s2k-cli` |
| [`plugin/`](plugin/README.md) | A Claude Code plugin that sends files, plans, specs, reports and summaries to your Kindle as reading editions | `/plugin marketplace add mjfura/send-2-kindle` then `/plugin install s2k@send-2-kindle` |
